# 와인 빈티지·수집 기능 테스트 가이드

## 전제

- 웹 크롤링 서면 허가 전에는 실제 Vivino 페이지에 접속하지 않는다.
- `샘플 3건 수집`은 외부 네트워크를 쓰지 않는 가상 Fixture다.
- 샘플은 항상 `HIDDEN`으로 등록되며 이름과 화면 배지에 `샘플/SAMPLE`이 표시된다.
- 운영 DB에 기존 와인이 없어도 V79는 기존 위스키·꼬냑 행을 수정하지 않는다.

## 로컬 기능 테스트

1. 로컬 MariaDB·Redis를 실행하고 API 환경변수를 준비한다.
2. API를 시작한다. Flyway가 V79까지 적용되고 Hibernate 스키마 검사가 성공해야 한다.
3. 웹을 시작하고 최고관리자 또는 관리자 계정으로 로그인한다.
4. `관리자 > 주류 > 와인 크롤링`에서 `샘플 3건 수집`을 누른다.
5. 크롤러의 `.env`에 아래 두 값이 API와 일치하는지 확인한다.

   ```properties
   CASKBYCASK_API_URL=http://127.0.0.1:8080
   CASKBYCASK_INTERNAL_KEY=<API와 같은 내부 키>
   ```

6. 크롤러 디렉터리에서 작업자를 한 번 실행한다.

   ```bash
   python wine_main.py
   ```

7. 관리자 와인 크롤링 화면에서 다음을 확인한다.

   - 실행 상태 `성공`, 진행 `3/3`, 등록 `3`
   - 건별 결과의 Vivino 기준 영문명·빈티지·마스터/빈티지 링크
   - 같은 Fixture를 다시 실행하면 등록 `0`, 중복 `3`, 건별 `중복 PASS`
   - 등록 데이터가 `HIDDEN` 상태

8. `마스터·국문명 수정`에서 국문명을 직접 입력하고 저장한다. 입력 전에는 `국문명 입력 필요` 버튼이 비활성화되어야 한다.
9. 결과 목록으로 돌아와 `검수 완료·공개`를 누르고 마스터와 해당 빈티지가 모두 ACTIVE인지 확인한다.
10. 사용자 한국어 화면에서 국문명 입력 전 임시 데이터는 영문명 하나만, 입력 후 데이터는 국문명 주제목·영문 부제목으로 표시되는지 확인한다.
11. `빈티지 보기`에서 대표 이미지 미리보기의 우측 하단에 `VIVINO · SAMPLE`, 점수, 참여 수가 보이는지 확인한다.
12. 관리자 와인 직접 등록에서 빈티지 연도와 `빈티지 없음(NV)` 체크박스를 각각 저장해 본다.
13. 사용자 리뷰 작성·상세 화면의 빈티지 선택 상자를 확인한다.

## 실패·Slack 테스트

Fixture JSON 사본에서 `country`를 지운 뒤 `WINE_FIXTURE_PATH`를 그 사본으로 지정한다.
실행 결과가 `REQUIRED_FIELD_MISSING`으로 남고 Slack에 아래 세 항목이 포함되어야 한다.

(`producerNameEn`은 필수값이 아니다. 등록되지 않은 와이너리로 바꾸면 실패가 아니라
`PRODUCER_UNRESOLVED` 사유를 단 CREATED 항목이 되고, 생산자 없이 HIDDEN으로 저장된다.)

- 와인명
- 원문 링크
- 실패 사유

테스트가 끝나면 기본 Fixture 경로로 되돌린다. 운영 데이터나 기존 Fixture 파일 자체를 수정하지 않는다.

## 운영 배포 후 확인

1. API 배포 시 Flyway V79 적용 로그와 API health를 확인한다.
2. 웹·크롤러를 함께 배포하고 다음을 확인한다.

   ```bash
   crontab -l | grep run-wine.sh
   tail -n 100 /app/caskbycask-crawler/logs/wine-cron.log
   ```

3. 서면 허가 전에는 관리자 설정을 `Fixture`, `웹 크롤링 허가 확인 OFF`, `자동 수집 OFF`로 유지한다.
4. 운영에서 샘플이 꼭 필요하면 최대 3건만 실행하고, 캡처가 끝난 뒤에도 `HIDDEN`을 유지하거나 관리자에서 삭제한다.
5. 서면 허가 후 허용된 페이지와 데이터 범위를 `VIVINO_START_URLS`에 반영하고 이용 허가 근거를 입력한다. API URL·토큰은 사용하지 않는다.
6. 수동 LIVE 웹 크롤링 1회로 영문명·중복 PASS·국문명 수동 검수·Slack을 확인한 뒤 자동 수집을 켠다.

## 합격 기준

- 시간당 LIVE 예약량이 10건을 넘지 않는다.
- 같은 외부 ID 또는 같은 생산자·영문명·빈티지는 추가 행을 만들지 않는다.
- 국문명 미입력 상태에서는 마스터와 빈티지를 사용자에게 공개할 수 없다.
- 한국어 사용자 화면에서도 국문명이 없으면 동일 영문명을 두 번 표시하지 않는다.
- 실패 건은 관리자 이력과 Slack 양쪽에서 원인을 확인할 수 있다.
- 위스키·꼬냑의 등록·상세·리뷰 선택 동작에 변화가 없다.
