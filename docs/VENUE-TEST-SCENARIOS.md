# 주류 장소(Venue) 지도 — 테스트 시나리오

릴리스 1 범위: 장소 DB · 지도 앱 · 사진 5장 댓글 · 리뷰 "마신 곳" 태그 · 주류 상세 연계 ·
제보/승인 · 공유 링크 해석 · SEO 문서 페이지 · 사이트맵.

이 문서는 두 부분이다.
- **A. 자동화** — CI/로컬에서 명령 한 줄로 도는 것. 회귀를 여기서 막는다.
- **B. 수동** — 사람 눈이 필요한 것(지도 렌더, 제스처, 라벨 표기). 자동화가 대신할 수 없는 것만 남겼다.

---

## 0. 사전 준비

```bash
cd caskbycask-api && ./gradlew bootRun --args='--spring.profiles.active=local'
```
```bash
cd caskbycask-web && npm run dev
```

수동 시나리오는 기능 플래그를 켜야 한다. 끈 상태의 동작(§B-0)도 따로 확인한다.

| 위치 | 값 |
|---|---|
| API 환경변수 | `VENUE_ENABLED=true` |
| 웹 환경변수 | `NEXT_PUBLIC_VENUE_ENABLED=true` |
| 링크 리졸버(선택) | `VENUE_LINK_RESOLVER_ENABLED=true` |
| 지오코더(선택) | `VENUE_GEOCODER_ENABLED=true` |

## B. 수동 시나리오

### B-0. 기능 플래그 (출시 전 동작)

## C. 알려진 한계 (테스트 대상 아님)

- **라벨 오버라이드는 라벨까지만** — 벤더 스타일이 경계선을 다르게 그리면 고칠 수 없다.
  완전한 통제는 자체 추출 Protomaps `.pmtiles`뿐이고, 그래서 타일 소스를 스왑 가능하게 뒀다.
- **OpenFreeMap 공개 인스턴스는 SLA가 없다** — 그래서 지도는 progressive enhancement다.
  B-5-2가 그 전제를 지킨다.
- **네이버 단축 링크는 원리상 좌표가 없다** — 공식 API 키를 넣기 전까지 수동 핀이 정상 경로다.
- **구글 링크 확장은 약관상 회색지대** — 기본값 off이며 켜는 것은 운영자의 명시적 결정이다.
- **댓글 이모지 반응은 릴리스 1 범위 밖** — 신고·숨김은 들어갔고 반응만 빠졌다.
- **장소 문서 페이지의 SSR 제목은 라우트 기본값** — `/producers/{id}`와 같은 수준이다.
  하이드레이션 후 `SeoMeta`가 실제 제목·JSON-LD로 교체한다.
