확인 포인트 2 — A′는 A의 장점과 B의 정확도를 동시에 가진다. A′ 탭의 전송량 계측값을 보세요. 실제 지리 데이터를 오프라인에서 단순화하면 B의 MB 단위가 수십 KB로 줄고, 런타임 의존성과 SSR 문제도 사라집니다. A′의 생성 스크립트는 개발 시에만 1회 실행되며 산출물(SVG path 문자열)만 저장소에 커밋됩니다.
